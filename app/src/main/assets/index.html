Day-by-day

Open-Meteo marine + weather · NOAA tides

Marine and wind forecast data: Open-Meteo. Live buoy observations: NOAA/NDBC station 44065 via an IOOS ERDDAP mirror so the browser can access the feed without a custom server. Tide predictions: NOAA CO-OPS Sandy Hook, NJ station 8531680, hourly predictions in local time, feet relative to MLLW. If NOAA is unavailable, the app automatically falls back to Open-Meteo modeled sea level. The breaking-face estimate is a Rockaway-specific heuristic: it converts directional wave-energy input (roughly H²×T) into an estimated face-height range and is intentionally shown as a range rather than a precise prediction. It is not a bathymetric wave-transformation model. The score is a board-selection heuristic, not a surf-safety rating; Rockaway's sandbars, currents and breaking size can differ materially from offshore model output.

Scoring assumptions

These values define a good session for the active board. Each board keeps its own scoring profile.

Relative swell energy = swell height² × period, using feet and seconds. Breaking-face estimates use directional H²×T energy and are displayed as a range; they are not literal nearshore-model output.
